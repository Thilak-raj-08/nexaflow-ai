# NexaFlow AI — Multi-Page Developer Cloud & Agile SaaS Platform

Built by **Jeyarajan Thilakraj** (`@Thilak-raj-08`).

## Pages & Architecture
- **`/` (Platform Overview)**: Interactive ROI & Engineering Velocity Calculator, Multi-Module Architecture Preview, and Customer Case Studies.
- **`/studio` (AI Code & SQL Studio)**: Interactive static analysis and security refactoring engine for React, Laravel/PHP, and MySQL.
- **`/kanban` (Agile Sprint Workspace)**: 4-stage Kanban board (*Backlog → In Progress → Code Review → Completed*) with live story-point velocity tracking.
- **`/analytics` (Cloud FinOps & Telemetry)**: Real-time infrastructure cost ledger, API latency distribution, and deployment telemetry.
- **`/pricing` (Plans & Seat Calculator)**: Interactive Monthly/Annual billing switcher, dynamic team seat estimator, and technical FAQ.

## Tech Stack
- **Framework**: Next.js 16 (App Router) & React 19
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Remix Icons (`react-icons/ri`)
